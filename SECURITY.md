# Security Policy

## Supported versions

This is a learning repository. Security fixes and documentation corrections
are prioritized on the latest `main` branch.

## Reporting a vulnerability

If you find a security issue, please do not open a public issue containing
exploit details.

Open a private security advisory through GitHub, or contact the maintainer
directly with:

- A clear description of the issue.
- Steps to reproduce.
- Potential impact.
- Any suggested mitigation.

## Safe use of AI tools

This repository teaches AI-assisted testing. Users must not:

- Submit credentials, API keys, tokens, or session cookies to AI tools.
- Paste customer data, production data, or confidential source code into prompts.
- Run unreviewed commands generated by an AI agent.
- Grant broad filesystem, shell, browser, or repository permissions without understanding the consequences.
- Commit secrets or generated artifacts containing sensitive information.

Use dedicated test environments, synthetic data, and least-privilege access.
