# Exercise: Run and Analyze Playwright Tests

Use a CLI agent to run the Playwright suite and interpret the results.

## Objective

By the end of this exercise, you should be able to:

- Run Playwright tests through a CLI agent.
- Interpret pass, failure, skip, and flaky results.
- Identify useful artifacts such as traces, screenshots, and reports.
- Ask for an evidence-based analysis rather than an immediate code change.

## Steps

1. Start from a clean branch.
2. Use the prompt in `prompt.md`.
3. Save the agent response as `test-analysis.md`.
4. Review it with `review-checklist.md`.
5. Run the relevant tests yourself to verify the agent’s findings.
6. Document any incorrect conclusions.

## Definition of done

- The agent runs the test suite.
- The agent reports the result accurately.
- The agent identifies failures and relevant artifacts.
- The agent distinguishes evidence from speculation.
- You verify the findings independently.
