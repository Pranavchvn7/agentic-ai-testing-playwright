# Test Analysis Review Checklist

Check whether the agent:

- [ ] Ran the correct test command.
- [ ] Reported results accurately.
- [ ] Identified all failures.
- [ ] Quoted relevant error messages.
- [ ] Referenced traces, screenshots, or videos where available.
- [ ] Distinguished facts from assumptions.
- [ ] Considered application and test defects.
- [ ] Avoided claiming an unproven root cause.
- [ ] Recommended a focused next action.
- [ ] Did not modify files without approval.
