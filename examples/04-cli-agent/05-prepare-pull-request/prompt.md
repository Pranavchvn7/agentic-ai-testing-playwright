# Pull Request Draft Prompt

```text
You are a senior QA engineer preparing a pull request.

Review the current Git diff and recent commits.

Do not modify files.

Create a pull-request draft that includes:

1. Title
2. Problem statement
3. What changed
4. Why it changed
5. Evidence: test command, result, trace, screenshot, or report
6. Risks and limitations
7. Reviewer focus areas
8. Suggested rollback plan

Use clear, concise language.
Do not exaggerate coverage or claim testing that was not performed.
```
