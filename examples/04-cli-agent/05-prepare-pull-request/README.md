# Exercise: Prepare a Reviewable Pull Request

Use a CLI agent to prepare a clear, reviewable pull request for a small QA
improvement.

## Objective

By the end of this exercise, you should be able to:

- Use an AI agent to summarize a change.
- Create a clear pull-request description.
- Link evidence and test results.
- Request meaningful review.

## Steps

1. Complete a small change on a feature branch.
2. Run the relevant tests.
3. Use the prompt in `prompt.md`.
4. Save the draft as `pull-request-draft.md`.
5. Review and improve the draft.
6. Push the branch.
7. Open a pull request on GitHub.
8. Request review from a peer or mentor.

## Definition of done

- The branch contains one focused change.
- The pull request explains the problem, change, evidence, and risks.
- Test results are included or linked.
- The change is easy for a reviewer to understand.
