# Repository Onboarding Prompt

```text
You are a senior QA engineer onboarding to this repository.

Inspect the repository structure, documentation, package files, Playwright
configuration, demo application, and existing tests.

Do not modify any files.

Create a concise onboarding summary that includes:

1. Project purpose
2. Repository structure
3. Demo application architecture
4. Frontend and API entry points
5. Commands to install dependencies
6. Commands to run the application
7. Commands to run Playwright tests
8. Test configuration details
9. Existing test coverage
10. Missing coverage and quality risks
11. Potential flakiness risks
12. Questions that need clarification

Base your response only on files and commands available in this repository.
Clearly separate facts from assumptions.
```
