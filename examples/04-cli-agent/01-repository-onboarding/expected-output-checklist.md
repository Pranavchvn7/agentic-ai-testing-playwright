# Repository Onboarding Review Checklist

Check whether the agent:

- [ ] Correctly identifies the demo app structure.
- [ ] Explains the client and server relationship.
- [ ] Identifies the Playwright configuration.
- [ ] Lists accurate setup and run commands.
- [ ] Identifies existing tests.
- [ ] Identifies missing coverage.
- [ ] Identifies likely flakiness risks.
- [ ] Separates facts from assumptions.
- [ ] Does not invent files, commands, or features.
- [ ] Does not modify files.
