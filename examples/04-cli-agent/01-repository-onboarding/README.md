# Exercise: Repository Onboarding

Use a CLI agent to understand the ShopLite repository and Playwright test
setup.

## Objective

By the end of this exercise, you should be able to:

- Use an AI agent to create a repository overview.
- Identify important test files and configuration.
- Understand how to run the app and tests.
- Identify risks and gaps before changing code.

## Steps

1. Ensure your repository is clean:

```bash
git status
```

2. Use the prompt in `prompt.md`.

3. Save the agent response as `repository-overview.md`.

4. Review it with `expected-output-checklist.md`.

5. Correct anything the agent misunderstood.

## Definition of done

- The agent explains the project structure.
- The agent identifies the demo app, API, client, and test setup.
- The agent lists the commands needed to run the app and tests.
- The agent identifies test risks without modifying files.
