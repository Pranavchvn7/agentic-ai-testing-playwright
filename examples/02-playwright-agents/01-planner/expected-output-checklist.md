# Planner Output Review Checklist

A good planner output should include:

- [ ] A clear test objective.
- [ ] The checkout user journey.
- [ ] Positive scenarios.
- [ ] Required-field validation scenarios.
- [ ] Invalid email, phone, and postal-code scenarios.
- [ ] Coupon scenarios, including `SAVE10` and `EXPIRED10`.
- [ ] Empty-cart prevention.
- [ ] Duplicate submission prevention.
- [ ] Out-of-stock product handling.
- [ ] API failure handling.
- [ ] Accessibility checks.
- [ ] Clear priorities.
- [ ] Assumptions and open questions.

Reject or improve the plan if it:

- [ ] Invents features that do not exist.
- [ ] Uses vague expected results.
- [ ] Misses important business rules.
- [ ] Treats every scenario as equally important.
- [ ] Does not identify risks.
- [ ] Does not distinguish functional from accessibility coverage.
