# Healer Prompt

```text
The following Playwright test is failing.

Investigate the failure using the test output, trace, screenshots, and
application behavior.

Do not change application source code.

Identify:

1. The exact failure message
2. The likely root cause
3. Evidence supporting the root cause
4. The smallest safe test repair
5. Whether the failure indicates an application defect or a test defect
6. Remaining risks after the repair
7. Any changes you recommend but do not recommend applying automatically

Explain your reasoning before proposing a fix.
```
