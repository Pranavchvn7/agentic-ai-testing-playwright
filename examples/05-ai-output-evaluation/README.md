# Exercise: Evaluate AI Output

Evaluate an AI-generated test plan, test, or proposed fix using a structured
review process.

## Objective

By the end of this exercise, you should be able to:

- Evaluate AI output systematically.
- Separate evidence from assumptions.
- Identify weak assertions, brittle selectors, and missing coverage.
- Decide whether AI output is ready for a pull request.

## Steps

1. Choose one AI-generated artifact from an earlier exercise.
2. Copy `evaluation-template.md`.
3. Complete every section.
4. Identify at least three improvements.
5. Apply only approved improvements.
6. Re-run the relevant test.
7. Save the completed evaluation as `example-evaluation.md`.

## Definition of done

- The artifact is evaluated across all eight dimensions.
- Evidence is recorded for each conclusion.
- Improvements are prioritized.
- The final test passes.
- The evaluation explains what a human accepted, changed, or rejected.
