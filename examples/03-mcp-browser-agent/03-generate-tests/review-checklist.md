# MCP Test Review Checklist

Before accepting the generated test:

- [ ] The test objective is clear.
- [ ] The test verifies a real user journey.
- [ ] Assertions check meaningful outcomes.
- [ ] Selectors are stable and accessible.
- [ ] No arbitrary waits are used.
- [ ] Test data is synthetic.
- [ ] The test is independent.
- [ ] The test does not duplicate existing coverage.
- [ ] The test fails when the feature is broken.
- [ ] The test is suitable for the regression suite.
