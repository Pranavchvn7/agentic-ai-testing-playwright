# MCP Investigation Review Checklist

Check whether the agent:

- [ ] Reproduced the failure.
- [ ] Used browser evidence rather than assumptions.
- [ ] Separated facts from speculation.
- [ ] Identified the failing step.
- [ ] Compared expected and actual behavior.
- [ ] Considered both application and test defects.
- [ ] Proposed a minimal next action.
- [ ] Did not recommend hiding a real defect.
- [ ] Did not expose sensitive data.
- [ ] Provided a clear, evidence-based conclusion.
