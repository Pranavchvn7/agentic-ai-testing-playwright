# Exercise: Explore ShopLite and Create a Test Plan

Use Playwright MCP to explore the ShopLite catalog and cart journey, then
create a test plan based on observed behavior.

## Objective

By the end of this exercise, you should be able to:

- Use an MCP agent to explore a live application.
- Capture structured evidence from the browser.
- Create a test plan grounded in observed behavior.
- Identify missing risks and improve the agent’s plan.

## Steps

1. Start ShopLite.
2. Use the prompt in `prompt.md`.
3. Save the raw agent response as `mcp-exploration.md`.
4. Complete `evidence-template.md`.
5. Review the agent’s test plan with `review-checklist.md`.
6. Create `human-reviewed-test-plan.md`.
7. Identify at least three risks or gaps the agent missed.

## Definition of done

- The agent explored catalog, product detail, cart, and checkout entry.
- Evidence includes observed pages, controls, and user-visible behavior.
- The test plan includes functional, negative, boundary, and accessibility scenarios.
- You documented what the agent missed or got wrong.
