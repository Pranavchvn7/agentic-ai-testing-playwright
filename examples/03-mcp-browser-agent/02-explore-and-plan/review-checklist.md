# MCP Exploration Review Checklist

Check whether the agent:

- [ ] Explored the requested journeys.
- [ ] Based claims on observed browser behavior.
- [ ] Separated facts from assumptions.
- [ ] Identified important controls by accessible name.
- [ ] Identified empty, error, loading, and edge-case states.
- [ ] Identified risks relevant to customers and business outcomes.
- [ ] Did not invent unavailable features.
- [ ] Did not expose sensitive data.
- [ ] Produced testable scenarios.
- [ ] Prioritized risks sensibly.

Improve the plan if it misses:

- [ ] Empty cart behavior.
- [ ] Invalid form input.
- [ ] Coupon edge cases.
- [ ] Out-of-stock products.
- [ ] Duplicate submission.
- [ ] API failure behavior.
- [ ] Keyboard navigation.
- [ ] Screen-reader labels.
- [ ] Data boundary values.
