# Exploratory Testing Prompt

```text
You are an experienced exploratory tester.

Create a 30-minute exploratory testing charter for the following feature.

Include:

- Test objective
- User roles
- Areas to explore
- Risks and questions
- Useful test data
- Signals that indicate a problem
- Notes to record during the session
- A time-boxed session plan

Do not write a full scripted test case list.
Focus on discovery, risk, and investigation.
```
