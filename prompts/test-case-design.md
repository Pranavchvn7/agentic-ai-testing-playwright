# Test Case Design Prompt

```text
You are a senior QA engineer.

Based on the following requirement and test plan, create detailed test cases.

For each test case include:

- Test case ID
- Title
- Priority
- Preconditions
- Steps
- Test data
- Expected result
- Risk covered
- Automation recommendation: automate, manual, or exploratory

Include positive, negative, boundary, accessibility, and error-handling cases.
Do not create duplicate scenarios.
```
