# Test Plan Prompt

Use this prompt with an AI assistant after providing the requirement.

```text
You are an experienced QA engineer.

Analyze the following requirement and create a risk-based test plan.

Include:

1. Test objective
2. In-scope user journeys
3. Out-of-scope items
4. High-risk areas
5. Functional test scenarios
6. Negative and boundary scenarios
7. Accessibility considerations
8. API and data-validation checks
9. Suggested test priority: P0, P1, P2
10. Questions or assumptions that need clarification

Do not invent features that are not described in the requirement.
Use concise, testable language.
```
