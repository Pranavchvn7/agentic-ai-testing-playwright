# Bug Triage Prompt

```text
You are a QA engineer triaging a defect.

Based on the following information, help me create a high-quality bug report.

Include:

- Title
- Environment
- Preconditions
- Steps to reproduce
- Expected result
- Actual result
- Evidence to collect
- Possible severity and priority
- Questions to investigate
- Suggested next debugging steps

Do not claim a root cause without evidence.
```
