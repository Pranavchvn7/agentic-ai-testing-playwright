# Contributing

Thank you for helping improve **Agentic AI Testing with Playwright**.

This project is a practical learning resource for QA engineers. Contributions
should be clear, reproducible, safe, and useful to real testing teams.

## Ways to contribute

- Improve documentation or fix typos.
- Add a new exercise, prompt, or example.
- Improve the demo application.
- Add compatibility notes for AI tools and MCP clients.
- Report a bug or unclear instruction.
- Share a real-world lesson learned from using AI in testing.

## Before opening a pull request

1. Fork the repository and create a descriptive branch, such as
   `docs/mcp-setup` or `feat/checkout-agent-example`.
2. Keep changes focused on one improvement.
3. Follow the existing folder and documentation structure.
4. Include setup steps, commands, and expected results for new exercises.
5. Do not include credentials, tokens, private code, customer data, or
   production URLs.
6. Test documentation commands locally where possible.
7. Open a pull request with a clear description of what changed and why.

## Exercise quality checklist

A good exercise should include:

- A clear learning objective.
- Prerequisites and setup instructions.
- The prompt or command to run.
- Expected output or behavior.
- A review checklist for AI-generated work.
- Common failure modes and troubleshooting tips.
- A completed example where appropriate.
